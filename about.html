How we rank

Every score on AgentTested will come from an agent running the tool on the same standard task, not from press releases, traffic or who paid.

The scoring rubric (100 points)

  • Task success (40): did the tool complete the standard task for its use case?
  • Output quality (25): correctness, code/asset quality, how much fixing it needed.
  • Speed & effort (15): time and number of steps to a working result.
  • Cost & free tier (10): what it costs to get the job done; usable free tier.
  • Developer experience (10): setup, docs, reliability.

We publish the task, notes and evidence with each score, and re-test top tools regularly.

Rankings can't be bought

No one can pay to change a score or a position. Any sponsored placement will be clearly labeled and kept separate from rankings. Paying to be tested sooner, if we ever offer it, will never affect the result.

Where we are today

We haven't run tests yet. Current leaderboards list well-known tools with public facts only (official link, pricing, free tier) and are marked Preliminary, testing in progress.
