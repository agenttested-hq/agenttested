Video to Game (fal)
Agent skill (Claude Code, Codex, Cursor, Gemini) that turns a short AI-generated gameplay video into a playable single-file Three.js browser game: it studies the frames, generates matching images, 3D models and sounds, then plays its own game to check it. MIT; 31 example games you can play. The skill is free, but asset generation runs on fal's paid API (the author reports about $6 per game).
Found 2026-10-30
Grim Prompter (Jim Manico)
Threat modeling for AI coding agents from a well-known app-security trainer: run /threat-model in Claude Code or $threat-model in Codex for a read-only review with findings cited to file and line, plus a mode for reviewing a branch. 36 architecture workflows and 29 method prompts. MIT, free.
Found 2026-10-30
Overtone captions
Caption files that re-cut themselves for 16:9 and 9:16 video, with a CLI and a video.js plugin. Re-cutting existing subtitles works offline with no key; transcription uses OpenAI/Azure keys or runs locally with whisper.cpp and Ollama. Handy for devlogs and trailers. MIT.
Found 2026-10-30
Floorplan
Claude Code / Codex plugin that reads your codebase and draws an interactive, plain-English map of every part, file and web request, then shows which parts the agent touched after each change. MIT, zero dependencies, runs locally with no telemetry; questions go through your own Claude or Codex account. Live demo at haydenschmitty.github.io/floorplan-demo. Created Oct 27, 2026 (v0.2.2 Oct 29).
Found 2026-10-29

MIT; installs as a plugin marketplace in Claude Code or Codex, or copies into ~/.agents/skills. Released Oct 28, 2026.

DevBox (RudderStack)
Self-hosted autonomous engineering harness: hand it a ticket (CLI or Linear) and it plans, codes, runs tests, reviews its own diff and opens a draft PR, one sandbox per task with placeholder tokens swapped in by an egress proxy. MIT; runs on Docker Compose or Kubernetes with your own OpenAI or Anthropic key (model usage is billed by your provider). Open-sourced Oct 27, 2026.
