pixelfx (patch.gg)
244 pixel-art effects and animations for games (fire, explosions, magic, weather, UI, pickups, critters), each a small piece of code: play them in the browser gallery, recolor and mirror them, drop them into a browser game or export sprite sheets for Godot, Unity or any engine. Ships a Claude Code skill that drafts, renders, looks at and refines new effects. MIT, free; open-sourced Oct 30 and past 3,000 GitHub stars in two days. Live gallery at patch-gg.github.io/pixelfx.
Found 2026-11-02
stack-diagram
Agent skill for Claude Code, Codex, Cursor and other skills-compatible agents: describe your stack in one sentence and get an architecture diagram with the official vendor logos, as a single HTML file, PNG or React component. MIT, free, no account; it fetches logos from public icon libraries. It offers to post your diagram to a public gallery, but only if you say yes. Released Nov 1, 760+ stars in its first day.
Found 2026-11-02
teardown
Claude Code skill that turns any machine into an interactive 3D simulator you can take apart: ask how an engine, watch or excavator arm works and it builds one offline three.js page with live readouts and a guided tour, plus optional 60 fps video export. MIT, free skill (needs Node 20+; ffmpeg for video). Three example machines included. Created Oct 30, 1,000+ stars.
Found 2026-11-02
Video to Game (fal)
Agent skill (Claude Code, Codex, Cursor, Gemini) that turns a short AI-generated gameplay video into a playable single-file Three.js browser game: it studies the frames, generates matching images, 3D models and sounds, then plays its own game to check it. MIT; 31 example games you can play. The skill is free, but asset generation runs on fal's paid API (the author reports about $6 per game).
Found 2026-10-30
Grim Prompter (Jim Manico)
Threat modeling for AI coding agents from a well-known app-security trainer: run /threat-model in Claude Code or $threat-model in Codex for a read-only review with findings cited to file and line, plus a mode for reviewing a branch. 36 architecture workflows and 29 method prompts. MIT, free.
Found 2026-10-30
Overtone captions
Caption files that re-cut themselves for 16:9 and 9:16 video, with a CLI and a video.js plugin. Re-cutting existing subtitles works offline with no key; transcription uses OpenAI/Azure keys or runs locally with whisper.cpp and Ollama. Handy for devlogs and trailers. MIT.

MIT, zero dependencies, runs locally with no telemetry; questions go through your own Claude or Codex account. Live demo at haydenschmitty.github.io/floorplan-demo. Created Oct 27, 2026 (v0.2.2 Oct 29).
