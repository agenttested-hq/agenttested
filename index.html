AI tools our discovery agents found 2026-11-03 to 2026-11-09: 18 listed below, not yet tested or scored.

claude-work-mode
Claude Code plugin that switches session work modes with one slash command: auto (don't stop for reversible local steps; hard stops like installs, payments and outgoing messages are queued for one end-of-run report), out (delegate verifiable batch work to subagents), wrap (converge and list open decisions). Optional hook gates. MIT; /plugin install work-mode --marketplace danyuchn/claude-work-mode. About 170 stars / 11 forks, created Nov 8. Disclosed: needs Claude Code 2.1.314+; the gates need bash, jq, git and python3. We scanned the hooks and found no network or key access; we have not run it.
Found 2026-11-09
HyperFlow H3 Flash
Open-weights (Apache-2.0) 13.7B few-step video-plus-audio generator, a compressed version of MiniMax-H3: 5.2-15 s clips at 24 fps with stereo sound in 4-8 steps. Runs via ComfyUI/GGUF on 24-32 GB consumer GPUs (Q4_K_M is 9.1 GB, 16 GB system RAM) or Python INT8 on data-center cards; about 92 s per 5 s clip on one RTX 5090. Show HN Nov 8 (~80 pts), ~150 stars. Disclosed: needs a 24 GB+ GPU, so it is not free-tier friendly; base-model license terms apply to weights, check the Hugging Face card; not tested by us.
Found 2026-11-09
agent-manager
Local terminal app (tmux TUI) that runs Claude Code, Codex, OpenCode, Gemini CLI, Pi, Cursor CLI and other coding-agent CLIs side by side with live status, project groups, diff review and fork sessions. Uses your existing installs and subscriptions. Apache-2.0; brew install agent-manager (macOS/Linux); Scoop on Windows. About 650 stars / 70 forks as of Nov 7. Disclosed: not a sandbox; each session is your own CLI as-is.
Found 2026-11-07
Stroq
Local audit and guard for Claude Code, Codex and Cursor sessions: finds known secrets that left your machine, then installs local hooks that trace risky commands back to the text that dictated them. Apache-2.0; npx @stroq/cli; no account, no telemetry (writes a small cache under ~/.stroq). Show HN Nov 5 (~90 pts). About 200 stars. Disclosed: reads your local session and key files (prints key names, never values).
Found 2026-11-07
sand3d
Python library for writing 3D objects as short programs over Blender's bpy, built so an LLM can author parts, joints and assemblies in a few hundred tokens (the whole API fits in about 3,600 tokens). Exports GLB, URDF, USDA, OBJ and STL; deterministic bit-for-bit meshes. Apache-2.0, free; created Nov 3, about 500 stars. Docs and gallery at sand3d.sandflow.ai; Hugging Face explorer. Needs Python 3.11/3.13 (bpy comes with it). Disclosed: you bring the model that writes the sand3d programs.
Found 2026-11-06
LivLiv Player
Lightweight 2.5D character player for the web (~30 KB gzipped core, WebGL2, no dependencies): lip sync from mic/audio/video and optional webcam face tracking (MediaPipe), one API for LivLiv, VRM and PNGTuber characters, plus 21 featured characters ready to drop in. Apache-2.0, free npm package @livliv-dev/player; created Nov 4, about 700 stars. Live demo at livliv-dev.github.io/player. Disclosed: face tracking pulls in @mediapipe/tasks-vision only when you import it.

pixel-gif-sticker-pack
Codex / Claude Code skill that turns a character reference into a chat GIF sticker pack (or a short mascot brand film): pixel, illustration or photographic looks, light-motion or articulated actions, with local Python/Pillow exporters and a visual review gate. MIT, free; created Nov 5, about 510 stars, 242 example stickers in-repo. Disclosed: new pose art uses whatever image model your agent already has; the exporters themselves need no API key.

Zerg Client
Coding-agent harness (ztc) that owns its own terminal multiplexer: ask for Vim or htop and panes open beside the agent; panes can hold more agents on different models. Evaluation beta on Product Hunt Nov 5; desktop/interactive client for Mac Apple silicon (v0.11.0-beta.1), headless on macOS/Linux/Windows. Free to evaluate under the Zerg Source Available License; sign in with ZergAI or bring your own OpenAI/DeepSeek key. Disclosed: not open source; ongoing commercial use needs a separate license; model usage billed separately; Windows/Linux desktop apps still "coming soon".

Rerun
Self-hostable open-source AI coworkers (AGPL-3.0): a Foreman plans a team, each coworker gets its own memory, skills and computer, and they ask before sending, paying or deleting. Works with Gmail, Slack, Notion, GitHub, Linear and 200+ other tools (plus any MCP server), on an API key or the Claude/ChatGPT subscription you already pay for. Docker Compose self-host (docs.rerun.build/self-host) or Rerun Cloud. Product Hunt Nov 5; GitHub repo from Oct 29, about 694 stars and v0.7.0 on Nov 4. Disclosed: needs your own model access; first self-host build wants ~6 GB RAM / 40 GB disk and a free Supabase project.
Found 2026-11-05
Cinecode
Claude Code / Cursor skill that makes short films, long YouTube videos, ads, explainers and music videos as code: the agent writes the script, builds every frame in three.js (or 2D/paint/ink looks), designs the sound and hands you a finished MP4 rendered in headless Chrome. MIT, free; created Nov 3, about 330 GitHub stars. Needs Node 22+, Python 3, ffmpeg and Chrome on your machine; optional narrator uses your own Gemini free-tier key, ElevenLabs or a free Turkish voice. Install is a git clone into ~/.claude/skills (or Cursor skills), not a curl | sh.

Sketchy
Layout engine for AI diagrams: the model says what to draw and label; Sketchy places parts, routes wires and walks you through steps. Hand-drawn interactive drawings in Claude chat (skill zip) or as an MCP server in Claude Code, Cursor and VS Code — systems, CS/ML concepts, your own repo (click a box to open the file), Arduino/ESP32 circuits and labeled photos. MIT, free; Product Hunt Nov 4, v0.1.8 Nov 3, about 196 GitHub stars. Local photo labeling uses Florence-2 on your computer.

OpenMail
Email API and inboxes built for AI agents: each agent gets its own address on your domain (or openmail.sh), replies arrive over webhook or WebSocket, attachments land as plain text, and there is a hosted MCP server plus Hermes / Claude Code / CLI plugins. Product Hunt Nov 4. Free plan with no card: 3 inboxes, 3,000 emails/month, 3 GB (OpenMail footer on Free). Pro from €9/mo. Built and hosted in the EU. Disclosed: SaaS, not open source; Free has a daily send cap.
Found 2026-11-05
Agent Autoloop
Runs Claude Code, Codex or any command-line agent that takes a prompt and prints a reply in the background on your Mac or Linux machine: cron jobs, new GitHub issues and error reports become tasks. When the agent needs your call (deleting data, spending money, messaging someone) it sends a card to Slack, Discord, Feishu, DingTalk, WeCom or a desktop notification and exits, so no tokens burn while it waits; your answer resumes the same session. Small zero-dependency TypeScript kernel, everything else is a plugin. MIT, free; v1.0.0 released Nov 3 and about 1,650 GitHub stars in its first day. Needs Node 24 and an agent you're already signed in to. README is Chinese-first with an English version, and the one-line installer is a curl | sh script, so read it before you run it.

Three-Live (Google)
Open-source runtime from Google that takes AI-generated Three.js code, runs it in a sandbox with time and memory limits, and renders it natively: WebGL2 and WebXR on the web, Filament and Scene Viewer on Android, RealityKit and Quick Look on iOS and visionOS. Its browser playgrounds edit scenes and export GLB, USDZ and AR in one tap with no build. Apache-2.0, free; introduced on the Google Open Source Blog Nov 3 (v1.2.0). Developer preview (alpha) and "not an officially supported Google product"; you bring the model that writes the Three.js.
Found 2026-11-04
Recto
Free desktop design canvas for coding agents (Mac, Windows, Linux): it detects Claude Code, Codex, Cursor or OpenCode on your machine and runs them inside the app, so you can prompt a UI, motion, SVG or 3D design, then drag, resize and restyle it with the mouse, pin comments for the agent and reprompt. Designs are real HTML and CSS you can export; no MCP or API setup, everything runs locally. Shown on Show HN Nov 3 (v0.1.6, released Oct 29). Early: the app is not open source, its terms page is still "coming soon", and you need your own coding agent.
Found 2026-11-04
Claude Animated Shorts
Claude Code skill that makes 55-70 second vertical cartoon story shorts (2D characters in a painted 3D world, gliding cameras, synthesized music and sound effects) by writing a three.js scene and rendering it with Remotion on your own PC, with no AI video generator. Ships the full source of its example short. MIT, free; created Nov 1 and past 850 GitHub stars in two days. You need Node, Python, ffmpeg and Remotion (Remotion has its own license: free for individuals and small teams, larger companies need a paid license), and you bring your own voice-over.
Found 2026-11-03
UNCUT
A 7 MB headless coding-agent harness for scripts, CI and experiments: one static Go binary, four tools (read, write, replace, run a command), plain stdin/stdout or NDJSON events. It never summarizes or trims context, and stops with an error instead of passing off a cut-off answer as success. Works with any OpenAI-compatible endpoint or a local model, no telemetry. MIT, free; v0.1 released Nov 2, about 580 GitHub stars. Not a sandbox: shell commands run as your user, so use a container for untrusted tasks.
Found 2026-11-03
Flockbay
Desktop AI game maker built on the official Godot engine (Windows, macOS, Linux): its AI writes GDScript and scenes into a normal Godot 4 project on your disk, runs and playtests the game and fixes what breaks, and Claude Code, Codex or Cursor can drive it over MCP. Launched on Product Hunt Nov 2. Free download with no card; free hosted AI to start (needs an account) or free on your own Claude/ChatGPT plan or API key; paid plans from $20/month add hosted usage. The app itself is not open source.
